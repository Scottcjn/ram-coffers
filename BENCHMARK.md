# RAM Coffers vs llama.cpp Benchmark

## Overview

This benchmark script compares the inference performance of RAM Coffers against stock llama.cpp.

## Usage

```bash
python3 benchmark.py
```

## Output

- Token throughput (tokens/second)
- Latency measurements
- Memory usage comparison
- JSON results file

## System Requirements

- Python 3.8+
- RAM Coffers installation
- llama.cpp installation

## Results

Results are saved to `benchmark_results.json` with detailed metrics.
